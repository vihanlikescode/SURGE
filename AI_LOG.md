## 2026-10-09 — README update
Resource Grid for Emergency Use.
Its for hospitals and clinics to help them deal with power cuts. When the power goes out, it can affect the whole hospital, like the ICU, oxygen machines, lights, medicine fridges, labs and other important stuff. SURGE helps staff see how much backup power they have and about how long it might last. It also keeps an eye on medicine storage temperatures. The idea connects SDG 7, Affordable and Clean Energy, with SDG 3, Good Health and Well-being.
This is for a hackathon demo, so make it look really good and professional, but keep it simple enough for people to understand quickly. Please dont make it seem like a real hospital system or like it makes medical decisions.
Start with a welcome and login page for a demo account. Say clearly that the login is just for the demo, not real security, and dont ask for patient info. After login, let the user enter details about their hospital or clinic, like its name and location, number of rooms, grid status, generator capacity and fuel, battery size and charge, solar capacity, and whether the generator starts by itself or needs to be started manually.
Let the user add rooms and services like the ICU, oxygen, lights, communications, labs, pharmacy and wards. They should be able to enter how much power each one uses in kW and how important it is. Include extra details for ICU equipment. Also let them add cold storage units, what they store, the current temperature, the safe temperature range and about how long they can stay cold without power. They should be able to add, edit and remove rooms and storage units. Fill in some useful demo info so the dashboard isnt empty.
The main dashboard should show whether the grid is on or out, generator status, battery charge, solar power, current power use and estimated backup time left. Add a clear visual that shows where the power is coming from and where its going. Show each room and service, how much power it uses, its priority and controls to turn it on or off in the simulation. Add a battery runtime chart, cold storage status, safe temperature ranges and a timeline for events like outages, generator startup, low battery and temperature warnings.
Add controls to simulate a power outage and grid recovery. Let people change solar output and switch loads on or off. If the generator is set to manual, let them start and stop it themselves. Add an emergency plan area with general reminders like checking backup power, reviewing noncritical loads, checking medicine storage and coordinating a safe supply transfer. Make clear that staff need to use their own judgement.
The app should work without internet once its loaded. Simulate the grid, solar, generator, battery, hospital power use and storage temperatures in the browser. During a simulated outage, update battery charge, generator status, power use, estimated backup time and storage temperatures as the demo runs. Let people change which loads are on and show how that changes the estimated runtime. Warn if a storage unit goes outside its safe temperature range. Clearly label things as simulated or estimated. Dont say it uses live grid data, real weather, verified medical advice or AI unless those things are actually connected and working.
Use a calm, professional design with dark navy, teal and white, and use amber or red for warnings. Make it modern and nice to look at, with readable charts, good spacing and clear buttons. It should work on phones and computers, be keyboard friendly, show clear form errors and have a way to reset the demo.
Build it using React, TypeScript and Vite. Keep the simulation code separate from the screen design. Save the facility profile and demo settings in localStorage. Add a README explaining how to run it, what it does, how the simulation works, its limits and how to present the demo. Add install and offline support where possible. It shouldnt need API keys, paid services, an account or a backend.
Add an AUTHORSHIP.md file where our four person team can write down what we made ourselves and what AI helped with. Dont claim we did 60% ourselves and 40% with AI unless we actually checked that.
For the demo, open SURGE and use the demo login. Show the facility setup, including the generator, solar, battery, room loads, ICU equipment and cold storage. Trigger a grid outage and show how the backup power and estimated battery time change. Change a load and show the runtime estimate update. Look at the cold storage status and alerts, then restore the grid. Explain that this is a hackathon demo using simulated information, not a real hospital system.
